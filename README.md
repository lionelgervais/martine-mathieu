# Site de Martine Mathieu, peintre

Site vitrine statique (HTML, CSS et JavaScript, sans dépendance).

© Martine Mathieu. Les œuvres reproduites sur ce site sont protégées par le droit d’auteur.
Toute reproduction, même partielle, est interdite sans l’accord de l’artiste.

## Contenu du dépôt

- `index.html` : le site complet (accueil, galerie filtrable par thème, démarche, salons et expositions, contact).
- `images/` : tableaux (filigranés, 1000 pixels maximum) et affiches des salons.
- `404.html` : page affichée pour une adresse inexistante.
- `.nojekyll` : indique à GitHub Pages de publier les fichiers tels quels.

## Modifier le contenu

Tout se règle au début du script de `index.html`, dans la zone « CONTENU À MODIFIER » :
`OEUVRES` (tableaux et thèmes), `PORTRAIT`, `EXPOSITIONS` et `CONTACT`.
Les textes entre crochets restent à compléter.

Avant d’ajouter un tableau, appliquez-lui le même traitement que les autres
(filigrane « © Martine Mathieu », 1000 pixels maximum) pour garder la même protection.
